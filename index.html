Quick k:

Core vocabulary

  • Sample (n): a subset of a larger group. Formulas use n − 1 in the denominator.
  • Population (N): the entire group of interest. Formulas use N.
  • Mean (x̄ or μ): the average. x̄ for a sample, μ for a population.
  • Standard deviation (s or σ): typical distance of data from the mean, in the data's units.
  • Variance (s² or σ²): the standard deviation squared, in squared units.

Measures of location

  • Center: mean (Σx ÷ n), median (middle of sorted data, position (n + 1) ÷ 2), mode (most frequent; no mode / unimodal / bimodal / multimodal).
  • Quantiles: percentiles (100 parts), quartiles (4), quintiles (5), deciles (10).
  • Others: geometric mean (growth rates), harmonic mean (rates), midrange ((max + min) ÷ 2), trimean ((Q1 + 2Q2 + Q3) ÷ 4), winsorized mean (extremes replaced).
  • Weighted mean = Σ(w × x) ÷ Σw. Moving average = average of a period and the k − 1 before it. Missing value = mean × n − known sum.
  • Skew: right-skewed → Mode, Median, Mean (left to right); left-skewed → Mean, Median, Mode; symmetric → all equal.
  • Which to use: mean for symmetric data without outliers; median for skewed data or outliers; mode for categorical data; percentiles to describe a position (“top 10%”).

Discrete vs. continuous data

DiscreteContinuous
ValuesCountable, separate values (often whole numbers)Any value in a range, including fractions/decimals
Comes fromCountingMeasuring
ExamplesCars in a parking lot (no 2.5 cars), people in a room, a die roll (1–6)Height, time, distance, temperature, weight

Why does recorded data always look discrete? Reality (time, distance, temperature) is often continuous, but data we write down is chopped into finite pieces:

  1. Measurement resolution: rulers stop at millimetres, thermometers at 0.1°, so values get rounded (height 5.9 ft).
  2. Computers are binary: everything is stored as a finite string of 1s and 0s.
  3. Categorisation: we group continuous things into categories (“Under 18 / 18+”) so we can count and test them (e.g. Chi-squared tests).
  4. Sampling: continuous signals are recorded at fixed intervals (a CD samples sound 44,100 times per second).
  5. Storage: infinite detail can't be stored, so a photo becomes a grid of pixels.

So: a variable is truly discrete when it can only take countable values because you're counting (not just because a tool rounded it). Measured quantities stay continuous even if they're recorded to whole numbers.

Frequency tables

  • Lower / upper class limit: the smallest / largest value that can belong to a class (e.g. 48 – 65).
  • Class width = lower limit of next class − lower limit of this class (48 − 30 = 18).
  • Class boundaries: split the gap between classes in half. Gap = next lower limit − this upper limit (102 − 101 = 1). Lower boundary = lower limit − gap ÷ 2 (101.5); upper boundary = upper limit + gap ÷ 2 (65.5).
  • Midpoint = (lower limit + upper limit) ÷ 2.
  • Cumulative frequency = this class's frequency plus all classes before it (12 + 3 + 4 = 19).
  • Relative frequency = class frequency ÷ total frequency.

Rounding rule (variance / standard deviation)

Round the final answer to one more decimal place than the original data. Data 4, 8, 12 → 1 decimal. Data 4.5, 8.2 → 2 decimals.

Which rule do I use?

Problem says…Use
“bell-shaped” or “normal”Empirical Rule (68–95–99.7)
Any / unknown shapeChebyshev: 1 − 1/k²
“Which is more consistent?”Coefficient of Variation — smaller wins

Test-taking checklist

  1. Sample or population? Variance or standard deviation? (Variance is squared.)
  2. Bell-shaped (Empirical) or any shape (Chebyshev)?
  3. Check rounding instructions — count decimals in the original data first.
  4. For consistency questions, compute CV for both groups; the smaller CV is more consistent.
